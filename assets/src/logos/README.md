# Logo sources

The art in this project is built from the real marks so every character is recognizable.
All marks belong to their respective owners and are used here only to identify each provider.

| File | Source |
| --- | --- |
| `t3-nightly.svg` | Composed from [pingdotgg/t3code](https://github.com/pingdotgg/t3code) `assets/nightly/app-icon.icon` layers using the transforms in its `icon.json` (MIT, see `T3CODE-LICENSE`) |
| `t3-logo.svg` | pingdotgg/t3code `assets/prod/logo.svg` |
| `codex.svg` | Codex app mark, redrawn as vector |
| `claude-ai-icon.svg`, `openai_dark.svg`, `grok-dark.svg`, `cursor_light.svg`, `opencode-dark.svg`, `antigravity.svg` | pingdotgg/t3code `apps/marketing/public/harnesses` |
| `grok.svg`, `cursor.svg`, `opencode.svg`, `antigravity.svg` | The marks above placed on app-icon tiles |
| `muse.svg`, `pi.svg` | Path data from pingdotgg/t3code `packages/provider-muse` / `packages/provider-pi` |
| `mistral.svg`, `gemini.svg` | Icons from the ACP agent registry (`cdn.agentclientprotocol.com`), recolored in brand colors |

Clawd (Claude Code's mascot) is drawn in code in `src/render/characters.ts`.
